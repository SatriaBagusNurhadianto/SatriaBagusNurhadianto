### Featured — Corvus

<table>
<tr>
<td width="70%" valign="top">

**Corvus** is an OSINT-oriented metadata extraction and correlation toolkit.

It pulls structured signal out of files that most tools treat as opaque: EXIF and document metadata, ZIP archive contents, file hashes, and entropy/anomaly scoring to flag files that look tampered with or disguised. Extracted entities (people, devices, locations, identifiers) are correlated against each other through a graph model — backed by Neo4j or an in-memory graph for lighter runs — so relationships between artifacts surface instead of staying buried in a flat report. It also runs YARA rule matching and processes extraction jobs asynchronously so batches don't block on a single large file.

</td>
<td width="30%" valign="top">
